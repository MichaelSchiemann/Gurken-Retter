# Punktjäger

Eine klassische Labyrinth-Jagd fürs iPhone im Hochformat.

- Touch/Wisch-Steuerung und Steuerkreuz
- Startbildschirm
- Sound über WebAudio
- Powerpunkte und Geistermodus
- Als iPhone-Web-App installierbar

Öffnen: https://michaelschiemann.github.io/Gurken-Retter/pacman/

Auf dem iPhone: Link in Safari öffnen → Teilen → Zum Home-Bildschirm.
