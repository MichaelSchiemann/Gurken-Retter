Gurken-Retter
==============

Öffne index.html über einen kleinen Webserver oder lade den Ordner auf Webspace/GitHub Pages hoch.

iPhone-Installation:
1. Link in Safari öffnen.
2. Teilen-Symbol antippen.
3. „Zum Home-Bildschirm“ wählen.
4. Danach startet Gurken-Retter wie eine kleine App im Vollbild.

Lokaler Test am Computer:
python3 -m http.server 8000
Dann im Browser öffnen: http://localhost:8000
