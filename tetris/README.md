# Blockstapler

Ein iPhone-freundliches Tetris-Spiel als PWA.

- Touch- und Button-Steuerung
- Soundeffekte und dezente Hintergrundmusik per WebAudio
- Mute-Knopf
- Pause
- Schwierigkeitsstufen: Locker, Normal, Profi
- Highscore je Schwierigkeit
- Als iPhone-Web-App installierbar

Öffnen: https://michaelschiemann.github.io/Gurken-Retter/tetris/

Auf dem iPhone: Link in Safari öffnen → Teilen → Zum Home-Bildschirm.
