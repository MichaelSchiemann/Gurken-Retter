# Gurken-Sprung 🥒🏃

Ein kleines iPhone-freundliches Jump-and-Run-Spiel für die Gurken-Retter-Spielesammlung.

## Steuerung

- ◀ / ▶ halten: laufen
- SPRUNG: springen
- Rechner: Pfeiltasten oder WASD + Leertaste

## Erste Version

- Drei kurze Welten
- Gurken einsammeln
- Schnecken-Gegner
- Sprungfedern
- Flagge als Levelziel
- Highscore, Leben, Sound und Mute
- PWA mit Manifest, Icons und Service Worker
