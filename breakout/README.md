# Gurken-Breaker 🥒💥

Eine iPhone-freundliche Breakout-Variante für die Gurken-Retter-Spielesammlung.

## Steuerung

- Finger auf dem Bildschirm bewegen: Schläger bewegen
- 🚀 antippen oder Bildschirm antippen: Kugel starten
- ◀/▶ halten: Schläger bewegen
- Leertaste am Rechner: Kugel starten
- Modus: Locker / Normal / Profi

## Features

- Touch- und Tastatursteuerung
- Power-ups für breiten Schläger und Extraleben
- Level-Fortschritt, Highscore, Sound und Mute
- PWA mit Manifest, Icons und Service Worker
